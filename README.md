# TuneNest - 网易云音乐智能歌单分类

Chrome 浏览器插件，自动分类网易云音乐收藏歌单，按情绪、语种、地区、年代、风格创建新歌单。

## 功能

- **歌单 TXT 备份**：导出当前账号全部自建及收藏歌单，一歌单一文件，支持选择文件夹或下载 ZIP
- **歌单合并 / 移动**：单个或多个来源合入已有目标，支持在线歌单及本插件导出的 TXT
- **规则分类**：基于歌曲标签、歌手名、发行时间等元数据自动分类
- **AI 分类**：规则无法判定时，调用 DeepSeek API 进行智能分类
- **自动创建歌单**：一键在网易云创建分类后的新歌单
- **页面内嵌 UI**：悬浮按钮 + 侧边面板，不离开网易云页面即可操作

## 分类维度

| 维度 | 示例 |
|------|------|
| 情绪 | 激情、舒缓、悲伤、浪漫、欢快 |
| 语种 | 华语、英语、日语、韩语、粤语 |
| 地区 | 华语、欧美、日本、韩国 |
| 年代 | 70s、80s、90s、00s、10s、20s |
| 风格 | 流行、摇滚、电子、民谣、嘻哈、古典、ACG、国风等 |

## 加载插件

1. 运行 `npm run dev` 或 `npm run build`
2. 打开 Chrome → `chrome://extensions/`
3. 启用「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `dist/` 目录
5. 打开 [网易云音乐](https://music.163.com)，右下角会出现悬浮按钮

## 导出所有歌单 TXT

1. 登录网易云音乐，在插件主页选择「导出所有歌单 TXT」。
2. 选择本地文件夹，插件会在其中新建带时间的备份子目录；网页无法选择目录时使用「下载 ZIP」，下载完成后解压即可。
3. 普通歌单保存为「歌单名.txt」。Windows 禁用字符会替换为下划线，同名歌单通过歌单 ID 区分，避免覆盖。
4. 核对导出结果中的失败项及数量差异提示；无法读取的歌单单独列出，不会冒充导出成功。

TXT 使用 UTF-8 编码，开头的注释保存版本、账号、歌单 ID、创建人、导出时间及实际记录数，后续每行是一首歌的 JSON，例如：

```text
{"id":12345,"name":"示例歌曲","artists":["示例歌手"],"album":"示例专辑","durationMs":180000,"detailsAvailable":true}
```

歌曲 ID 是合并和去重依据，不按歌名猜测是否同一首歌。歌名中的换行、引号等以 JSON 转义保存。缺少详情时仍保存 ID，详情字段留空并标记为不可用。导出的是歌曲清单，不包含音频，也不是可自动恢复全部歌单状态的完整备份。

歌单统计总数可能与实际返回的 ID 数不同，文件只包含本次实际读取到的歌曲；界面会列出差异。重新导入时请保留原文件的首部和行数信息，截断、无效或重复 ID 的文件会被拒绝。

## 歌单合并 / 移动

1. 在插件主页选择「歌单合并 / 移动」。
2. 在「选择在线歌单」中勾选一个或多个本人创建的来源，再选择一个不同的自建目标歌单。在线操作无需先导出。
3. 也可切换「导入 TXT 备份」，选择一个或多个本插件导出的 TXT；ZIP 需先解压，同一来源一次只导入一份备份。
4. 在线来源默认勾选「移动」；TXT 默认仅复制。取消「移动」时，来源歌曲保留。TXT 移动要求备份账号、歌单创建人和当前登录账号一致，并重新读取对应在线来源，只移除备份中仍存在于来源的歌曲，保留备份后新增的歌曲。
5. 点击「预览本次合并」，核对来源、目标及新增、移除数量，再点击确认执行。来源歌单本身始终保留。

合并按歌曲 ID 去重，只向目标添加缺少的歌曲，保留目标原有歌曲及相对顺序。所有候选歌曲都确认在目标中以后，才开始逐批移除来源歌曲，每批最多 100 首；未读取到的歌曲不处理。

执行期间请勿在其他页面或客户端同时修改相关歌单。网易云没有跨歌单事务；请求失败、账号变化或内容与预期不符时会停止后续写入，重新读取并报告可核验的结果，读取失败显示未知。已加入目标的歌曲保留，不自动回滚或重试写入。需要继续时重新预览，避免重复使用旧计划。

开发验证可使用 Node.js 22 执行 `npm run test:playlists`，测试通过模拟网络校验导出、合并及原有对比清理，不会修改真实账号歌单。

## 配置 DeepSeek API

1. 点击插件图标 → 设置（或 `chrome://extensions/` → TuneNest → 选项）
2. 输入 DeepSeek API Key
3. 测试连通性后保存
