加载插件
运行 npm run dev 或 npm run build
打开 Chrome → chrome://extensions/
启用「开发者模式」
点击「加载已解压的扩展程序」，选择 dist/ 目录
打开 网易云音乐【https://music.163.com/】，右下角会出现悬浮按钮

配置 DeepSeek API
点击插件图标 → 设置（或 chrome://extensions/ → TuneNest → 选项）
输入 DeepSeek API Key
测试连通性后保存
